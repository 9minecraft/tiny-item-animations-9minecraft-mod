# Tiny Item Animations — Make Items Pop When You Move Them

Tiny Item Animations 9minecraft Mod adds bouncy visual pop effects to inventory slots when you pick up and move items. In normal gameplay, items sit still inside chest boxes and inventory grids without visual reaction. This mod makes every item grow slightly when picked up by the cursor and swell softly before settling when dropped into a new slot. It works on every standard menu screen including chests, barrels, furnaces, and custom modded containers.

## What this build is

An unofficial rebuild of **Trivaxy**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
